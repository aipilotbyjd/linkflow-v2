# Render Deployment

## Setup

### 1. Connect Repository
1. Go to render.com
2. New → Blueprint
3. Connect your GitHub repo
4. Select `deploy/platforms/render/render.yaml`

### 2. Configure Secrets
Add in Render dashboard → Environment

## Deploy

Render auto-deploys on git push.

## Logs

View in Render dashboard → Logs

## Scale

Upgrade plan in Render dashboard
